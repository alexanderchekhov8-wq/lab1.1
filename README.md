# Модель лесного пожара (Forest Fire Cellular Automaton)

Компьютерная модель клеточного автомата, реализованная на Python с использованием библиотек **NumPy** и **Matplotlib**. Программа демонстрирует распространение огня по лесному массиву, учитывает рост деревьев и случайные удары молнии, а также позволяет исследовать влияние плотности леса и параметров модели на динамику пожара.

---

## 1. Краткое описание модели

**Модель лесного пожара** — это вероятностный клеточный автомат, в котором каждая клетка решётки представляет участок леса. Возгорание распространяется локально: горящее дерево поджигает соседей, а на месте сгоревших со временем вырастают новые.

### Состояния клетки
Каждая клетка поля может находиться в одном из трёх состояний:
- **Пусто** (значение `0`) — сгоревшее дерево или свободная площадка
- **Дерево** (значение `1`) — зелёное, не горит
- **Горит** (значение `2`) — охвачено огнём

### Правила перехода
На каждом такте (шаге) состояние всех клеток обновляется **синхронно**:

1. **Горение → пусто.** Горящее дерево на следующем шаге становится пустой клеткой.
2. **Возгорание дерева.** Дерево загорается, если:
   - в его окрестности не меньше `k` горящих клеток,
   - с вероятностью `f` в него ударила молния (самовозгорание).
3. **Рост дерева.** На пустой клетке с вероятностью `p` вырастает новое дерево — но только если в её окрестности нет ни одной горящей клетки.

### Математическая модель

Пусть `F` — текущее состояние поля (матрица `m × n`, где `F[i,j] ∈ {0, 1, 2}`).
Пусть `N` — тип окрестности (фон Неймана — 4 соседа, или Мура — 8 соседей).

Число горящих соседей для клетки `(i,j)`:

```
B(i,j) = Σ  [ F(i+di, j+dj) = 2 ]     для (di, dj) ∈ N
```

Правила перехода:

```
F_new(i,j) = 0,  если F(i,j) = 2                                       — сгорело
F_new(i,j) = 2,  если F(i,j) = 1 и (B(i,j) ≥ k или ξ < f)              — загорелось
F_new(i,j) = 1,  если F(i,j) = 0 и B(i,j) = 0 и η < p                  — выросло
F_new(i,j) = F(i,j),  во всех остальных случаях                        — без изменений
```

Здесь `ξ` и `η` — независимые случайные величины, равномерно распределённые на `[0, 1)`.

### Граничные условия

Используются **фиксированные** границы: клетки за пределами поля считаются пустыми (`0`), то есть огонь и деревья за край не выходят. Программно это реализуется через `np.roll` со сбросом «завернувшихся» краёв в ноль.

### Реализация на Python

Модель реализована **векторно**: вместо перебора каждой клетки в цикле `for` используются булевы маски NumPy. Подсчёт горящих соседей выполняется через сдвиги массива (`np.roll`), что даёт ускорение на порядок по сравнению с поэлементной реализацией.

**Код функции `update_forest()` (фрагмент):**

```python
def update_forest(forest, p, f, k=1, neighborhood='moore'):
    new_forest = forest.copy()
    burning_neighbors = count_burning_neighbors(forest, neighborhood)

    is_empty   = (forest == EMPTY)
    is_tree    = (forest == TREE)
    is_burning = (forest == BURNING)

    # Правило 1: горящее дерево → пусто
    new_forest[is_burning] = EMPTY

    # Правило 2: возгорание (от соседей или от молнии)
    ignites_by_neighbor = is_tree & (burning_neighbors >= k)
    lightning = is_tree & (np.random.random(forest.shape) < f)
    new_forest[ignites_by_neighbor | lightning] = BURNING

    # Правило 3: рост дерева (если рядом нет горящих)
    can_grow = is_empty & (burning_neighbors == 0)
    grows = can_grow & (np.random.random(forest.shape) < p)
    new_forest[grows] = TREE

    return new_forest
```

Здесь:
- `count_burning_neighbors(...)` — считает число горящих соседей для каждой клетки через сдвиги;
- `is_empty / is_tree / is_burning` — булевы маски текущих состояний;
- `ignites_by_neighbor`, `lightning` — маски клеток, которые загораются по разным причинам;
- `can_grow`, `grows` — маска клеток, где может и где реально вырастает дерево.

## 2. Возможности и ограничения

### ✅ Возможности
- Три независимые программы: базовая модель, модель с CLI и исследовательская программа с 6 готовыми сценариями.
- Синхронное обновление поля — корректная реализация классического клеточного автомата.
- Два типа окрестности: **фон Неймана** (4 соседа) и **Мура** (8 соседей) — в `main.py` и `main2.py`.
- Вероятностные правила: рост дерева (`p`), удар молнии (`f`), порог возгорания (`k`).
- Автоматическое сохранение результатов: PNG-кадры, PNG-графики динамики и GIF-анимации (в `LR1.py`).
- Гибкий CLI с возможностью переопределения параметров «на лету» (`--override-p`, `--override-f` и т. д.).
- Воспроизводимость экспериментов: каждый сценарий использует фиксированный `seed` генератора случайных чисел.
- Анимация с подписями осей и текущей статистикой (число деревьев / горящих / пустых).

### ⚠️ Ограничения
- Поле имеет **конечный размер**; огонь не выходит за границы (фиксированные границы).
- Модель работает **только в 2D** и **синхронно** (все клетки обновляются одновременно).
- Начальные очаги возгорания в `main.py` и `main2.py` задаются **вручную** в коде — без них при малом `f` пожар может не начаться.
- В `LR1.py` используется **только окрестность фон Неймана** (для чистоты сравнения сценариев).
- Влияние **ветра** и **неоднородности ландшафта** (болота, реки, дороги) не моделируется.
- Параметры `p` и `f` подобраны так, чтобы динамика была интересной; при экстремальных значениях возможны вырожденные режимы (полное выгорание или мгновенное затухание).

## 3. Инструкция по запуску

### Требования
- Python **3.8+**
- Установленные библиотеки:
  - `numpy`
  - `matplotlib`
  - `pillow` (для сохранения GIF)

### Установка зависимостей
Откройте терминал в папке проекта и выполните:
```bash
pip install -r requirements.txt
```

### Запуск базовой модели
```bash
python main.py
```
Запустит одну симуляцию с параметрами по умолчанию (поле 200×200, плотность 0.6, `p=0.01`, `f=0.0005`, `k=1`, окрестность Мура), построит график динамики и сохранит `forest_fire.gif`.

### Запуск модели с CLI
```bash
python main2.py --size 150 --density 0.7 --steps 300
python main2.py -s 100 -d 0.6 -n von_neumann --no-plot
```

### Запуск исследовательских сценариев
```bash
python LR1.py --scenarios all                 # все 6 сценариев
python LR1.py -s 1 3 5                        # только сценарии 1, 3, 5
python LR1.py -s 2 --override-steps 300       # сценарий 2, но 300 шагов
python LR1.py -s 4 --override-p 0.1           # сценарий 4, но очень быстрый рост
python LR1.py --scenarios all --dpi 150       # все сценарии, но быстрее (меньше DPI)
```

### Что произойдёт (для `LR1.py`)
1. Для каждого выбранного сценария создастся набор файлов в `forest_fire_output/`:
   - `scenario_N_*_states.png` — 4 ключевых кадра эволюции.
   - `scenario_N_*_stats.png` — график динамики деревьев / горящих / пустых.
   - `scenario_N_*_animation.gif` — анимация всей симуляции.
2. В консоль выведется краткая сводка по финальному состоянию.

## 5. Как интерпретировать результаты

### Цветовая схема
- **Тёмно-серый/чёрный** (`#1a1a1a`) — пустая клетка или сгоревшее дерево.
- **Зелёный** (`#2d8a2d`) — живое дерево.
- **Оранжево-красный** (`#ff4500`) — горящее дерево.

### Что наблюдать в каждом сценарии (`LR1.py`)

#### 🔵 Сценарий 1 — Случайный лес с очагами
Плотность 50%, три очага возгорания в разных точках поля. Классическая картина: от каждого очага расходится **фронт огня**, оставляя за собой выжженную территорию. Через несколько десятков шагов фронты могут слиться, а затем пожар затухает из-за нехватки топлива. Демонстрирует **базовую динамику** модели.

#### 🟢 Сценарий 2 — Высокая плотность (80%)
Плотный лес: огню легко переходить от дерева к дереву. Пожар **распространяется быстро** и охватывает почти всё поле. Демонстрация **связности** леса как ключевого фактора масштаба катастрофы.

#### 🟡 Сценарий 3 — Низкая плотность (20%)
Разреженный лес: расстояния между деревьями велики, огонь **часто затухает сам**. Остаются отдельные небольшие очаги. Демонстрация **порогового эффекта**: при низкой плотности крупный пожар невозможен.

#### 🟠 Сценарий 4 — Быстрый рост (p = 0.05)
Лес восстанавливается очень быстро. Пожары **локальны**, поле почти всегда зелёное. Демонстрация **баланса** между ростом и горением: если рост побеждает, экосистема устойчива.

#### 🔴 Сценарий 5 — Удары молнии (f = 0.001)
Молнии поджигают деревья случайно по всему полю, а не только рядом с фронтом. Возникают **многочисленные независимые очаги**, пожар носит «пятнистый» характер.

#### ⚫ Сценарий 6 — Медленный рост (p = 0.001)
Лес почти не восстанавливается: после одного крупного пожара поле надолго остаётся пустым. Демонстрация **необратимого ущерба** при медленном восстановлении.

### Как читать графики динамики
- **Зелёная кривая** — число деревьев. Сначала падает (горят), потом может снова расти (восстановление).
- **Оранжевая кривая** — число горящих клеток. Имеет вид «горба»: разгорается, потом затухает.
- **Чёрная кривая** — число пустых клеток. Зеркально отражает сумму двух других.
- **Пересечение кривых** показывает, в какой момент модель переходит из режима «пожар» в режим «восстановление».

### Как читать GIF-файлы
- **Количество кадров** соответствует числу шагов симуляции.
- **Скорость** задаётся параметром `fps=10` при сохранении.
- Подписи осей `X` и `Y` — координаты клетки на поле.

## 7. Параметры модели и их влияние

### Основные параметры

| Параметр | Смысл | Типичное значение | Эффект увеличения |
|----------|-------|-------------------|-------------------|
| `m, n` | Размер поля | 100–200 | Больше пространства для распространения |
| `density` | Начальная плотность деревьев | 0.2–0.8 | Пожар становится масштабнее |
| `p` | Вероятность роста дерева | 0.001–0.05 | Лес быстрее восстанавливается |
| `f` | Вероятность удара молнии | 0.0001–0.001 | Больше случайных очагов |
| `k` | Порог горящих соседей | 1–3 | Пожару труднее распространяться |
| окрестность | `moore` / `von_neumann` | `moore` | Больше путей распространения |

### Что можно исследовать
- **Порог перколяции.** При какой плотности леса пожар начинает охватывать всё поле?
- **Роль молний.** Как `f` влияет на устойчивость экосистемы?
- **Баланс роста и горения.** При каких `(p, f)` система выходит на стационар?
- **Влияние окрестности.** Чем отличаются результаты для Мура и фон Неймана?
- **Чувствительность к seed.** Насколько сильно случайная реализация меняет итог?
